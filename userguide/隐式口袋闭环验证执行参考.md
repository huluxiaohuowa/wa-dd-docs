# 隐式口袋闭环验证执行参考

本参考用于把“隐式口袋发现工作流”从案例设计推进到一次可复核的 L0-L3 闭环验证。当前闭环不要求用户手工搭建 OpenFold3、GROMACS、PocketXMol 或 FEP 环境；所有计算应从 WA-DD Web 界面提交，并把中间结果登记为项目资产。

## 1. 验证目标

以 KRAS G12C 为模式靶点，验证 WA-DD 是否能完成以下闭环：

1. 导入并准备 APO 与 OPEN 对照结构。
2. 用 OpenFold3 生成候选构象。
3. 用 GROMACS `pocket_discovery` 验证候选口袋，并输出标准 `pocket` 资产。
4. 用 PocketXMol 基于 `pocket` 资产生成候选分子。
5. 用 OpenFold3 复合物预测和 FEP 结果判断候选分子的结合优势。

## 2. 成功标准

一次闭环验证完成时，应能从同一个项目中导出以下证据：

| 层级 | 必需输出 | 通过标准 |
| :--- | :--- | :--- |
| L0 基准验证 | 4OBE、6GJ8 的蛋白/准备后蛋白资产；ARS-1620 类似物配体资产；两组 FEP 结果 | OPEN 构象的 ΔG 比 APO 构象优 1.0 kcal/mol 以上 |
| L1 AI 预测 | OpenFold3 候选构象资产；与 6GJ8 Switch II 区域的 RMSD 对比表 | 至少 1 个候选构象 RMSD < 3.0 Å |
| L2 物理验证 | GROMACS `md_result` 资产；`pocket_analyzer_report.json`、`pocket_events.csv`、`pocket_volume.csv`；标准 `pocket` 资产 | AI 候选构象 RMSD 漂移 < 2.0 Å，且口袋事件与体积曲线支持口袋打开 |
| L3 闭环发现 | PocketXMol 候选分子 SDF；OpenFold3 复合物预测结果；Top 3 FEP 结果 | 至少 1 个新分子 ΔΔG < 0 |

## 3. 执行前检查

1. 登录 WA-DD Web，并进入本次验证专用项目。
2. 在“模型仓库”确认 OpenFold3 和 PocketXMol 模型处于可用状态。
3. 在“任务”或对应页面确认 GROMACS 与 FEP worker 可接收任务。
4. 确认任务输出中的文件按钮、资产详情文件按钮和“打包下载全部输出”均可打开或下载。

## 4. 第一阶段：基准资产准备

目标是建立 L0-L3 会复用的基准资产。

1. 在“项目总览”创建或选择项目，建议命名为 `cryptic-pocket-kras-g12c`。
2. 在“蛋白处理”通过 PDB ID 导入 `4OBE`，命名为 `KRAS_G12C_APO_4OBE`。
3. 在“蛋白处理”通过 PDB ID 导入 `6GJ8`，命名为 `KRAS_G12C_OPEN_6GJ8`。
4. 分别对两个蛋白资产运行蛋白准备，输出 `prepared_protein` 资产。
5. 在“配体处理”导入 ARS-1620 类似物 SDF 或 SMILES 列表，并运行配体准备。
6. 在项目资产列表确认 4OBE、6GJ8、准备后蛋白和准备后配体均可打开详情，且原始文件可下载。

第一阶段通过后，记录项目 ID、资产 ID、任务 ID 和输出文件名，作为后续 L0 FEP 与 L1 OpenFold3 的输入。

## 5. 第二阶段：L0 FEP 基准验证

1. 在“FEP / 分析”选择 `KRAS_G12C_APO_4OBE` 的准备后蛋白资产和准备后配体资产，提交 APO FEP。
2. 用相同配体资产和 `KRAS_G12C_OPEN_6GJ8` 的准备后蛋白资产提交 OPEN FEP。
3. 等待两个任务完成后，打开 FEP 输出资产，下载 JSON/CSV 结果。
4. 使用“打包下载全部输出”保存两个任务的完整结果包。
5. 比较两个构象下的 ΔG；若 OPEN 优于 APO 1.0 kcal/mol 以上，L0 通过。

## 6. 第三阶段：L1 OpenFold3 构象生成

1. 在“结构预测”选择 `KRAS_G12C_APO_4OBE` 或其准备后蛋白资产。
2. 添加 6GJ8、5VQ2、4TQ9 等模板结构资产，运行模板扰动预测。
3. 对已知配体或片段库运行配体诱导预测。
4. 从 OpenFold3 输出中筛选构象资产，计算 Switch II 区域与 6GJ8 的 RMSD。
5. 选择 RMSD < 3.0 Å 的构象进入 L2。

## 7. 第四阶段：L2 GROMACS 物理验证

1. 在“GROMACS / MD”选择 L1 候选构象和 6GJ8 基准构象。
2. 协议选择 `pocket_discovery`，使用 5 ns aMD 或当前资源允许的等效参数。
3. 等待任务完成后，打开 `md_result` 资产。
4. 检查 `pocket_analyzer_report.json`、`pocket_events.csv`、`pocket_volume.csv`、代表结构和标准 `pocket` 资产。
5. 使用“打包下载全部输出”保存完整 MD 与口袋分析结果。

## 8. 第五阶段：L3 配体生成与复合物验证

1. 在“分子生成”选择 L2 输出的标准 `pocket` 资产和对应蛋白/构象资产。
2. 用 PocketXMol 生成 10 个候选分子。
3. 在“结构预测”对 Top 候选分子运行 OpenFold3 复合物预测。
4. 在“FEP / 分析”对 Top 3 分子运行 FEP。
5. 汇总 ΔΔG、口袋事件、体积曲线、复合物结构和候选分子 SDF，形成最终证据包。

## 9. 需要人工判断的边界

当前平台能完成资产流、任务调度、标准 `pocket` 资产输出和任务结果打包下载；但以下判断仍需要研究者复核：

- OpenFold3 候选构象是否代表有效的 Switch II 打开状态。
- `pocket_discovery` 输出的候选口袋是否与目标药效团空间一致。
- RMSD、口袋体积和 FEP ΔΔG 是否足以支持“隐式口袋可药”的结论。
- 当前 pocket analyzer 是 MVP 几何与事件分析；fpocket、MDAnalysis、水网络和多帧评分增强可提高证据质量，但不阻断本闭环验证。
