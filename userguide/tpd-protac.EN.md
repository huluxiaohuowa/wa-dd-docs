# TPD / PROTAC

## Role

The TPD/PROTAC module is reserved for subsequent POI-E3 ternary complex, warhead, E3 ligand, and linker design workflows.

## Inputs

- POI pocket asset
- E3 ligase structure
- POI warhead
- E3 ligand

## Outputs

- PROTAC candidate assets
- ternary complex result assets

## API / Automation

This is currently a planning entry point; subsequent tasks will reuse the unified automation model of `project_id`, `asset_id`, and `job_id`.
